# Task 1 - Product Scoping

## Overview

This task focuses on designing an internal marketing analytics tool that helps teams quickly understand campaign performance across multiple channels.

The goal of the system is to reduce manual reporting effort, improve consistency in insights, and provide faster visibility into marketing performance.

## Included Files

- `product_brief.md` → Detailed product scope and decisions
- `diagrams/` → System architecture diagrams
- `wireframes/` → Dashboard wireframe concepts
- `walkthrough_notes.md` → Additional product reasoning and tradeoffs

- Product thinking

- User experience
- Data flow design
